Original village art

CTRL storybook cottages, roofline towers, gouache meadow cards, cumulus cloud paintings and linen clothing swatches are authored in this project. Original World Gacha-derived placements and footprints remain compatible with the navigation map. No new external building models are used.

Anime characters

Bundled VRoid Project models: Victoria Rubin and Fumiriya Sakurada. Embedded VRoid Hub permissions allow use by everyone, modification, commercial use and redistribution. Models are reused from the existing reviewed project library, not copied from a Ghibli film. Seven animated characters use two base models with palette variations, not seven distinct authored meshes.

Embedded VRoid usage terms

Adaptations: watercolor-like surface grading, four-tone foliage, alpha-cutout tufted canopy, painted leaf atlas, countryside atmosphere and shared travelling-gust vegetation wind. Full upstream demos were not imported.
