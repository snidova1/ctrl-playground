# Complete VRoid / AIRI reference characters

These complete, authored VRM characters are **AvatarSample_A** and **AvatarSample_B**, by **VRoid Project**. AIRI lists them as VRM presets in `packages/stage-ui/src/stores/display-models.ts`; AIRI's software MIT license is not being used as the models' license.

Model source URLs:
- https://dist.ayaka.moe/vrm-models/VRoid-Hub/AvatarSample-A/AvatarSample_A.vrm
- https://dist.ayaka.moe/vrm-models/VRoid-Hub/AvatarSample-B/AvatarSample_B.vrm

Each original model embeds a VRoid Hub conditions URL allowing avatar use by everyone, commercial use, alterations and redistribution, with attribution optional. The original embedded VRM metadata and conditions links remain in every high/mobile asset. Consult those conditions, rather than applying the unrelated modular bank's license or assuming CC0.

Changes: embedded image resizing using the existing runtime preparation script (1024px high / 512px mobile maximum). No donor head, skeleton, hair or clothes grafts; full authored geometry, rig and expressions retained. Provenance, original source hashes, prepared file hashes and metadata are in `provenance.json`.

Runtime customization additionally offers reviewed, native garment/hair component removal and bob reshaping on the same skin/rig. No source VRM binary is overwritten; face/body skin and expressions are preserved.

These characters keep their model-authored adornments by default. CTRL's older extra accessory overlays are disabled on these presets until their fitting/animation clearance is verified; the original complete model is unaffected.
