# Willow Common — asset credits

All runtime assets are served locally. Nothing is fetched from third-party asset CDNs.

## 3D props (CC0)
- **Kenney — Nature Kit** (`/kit/nature-kit`): trees, rocks, flowers, crops, fences, logs, tents, canoes. https://kenney.nl/assets/nature-kit · `kenney-nature.txt`
- **Kenney — Furniture Kit** (`/kit/furniture-kit`): home furniture. https://kenney.nl/assets/furniture-kit · `kenney-furniture.txt`
- **Kenney — Food Kit** (`/kit/food-kit`): item thumbnails and props. https://kenney.nl/assets/food-kit (CC0)
- **Kenney — Fantasy Town Kit 2.0** (`/kit/fantasy-town`): fountain, lanterns, market stalls, cart. https://kenney.nl/assets/fantasy-town-kit · `../fantasy-town/LICENSE.txt`

## Characters
- Anime VRM bodies in `/characters` — see `/characters/LICENSE.md`. `female.vrm`: pixiv Inc. VRM1_Constraint_Twist_Sample (VRM Public License 1.0: commercial use, modification and redistribution allowed). `female-b.vrm`: VRoid HairSample_Female (CC0). `male.vrm`: VRoid HairSample_Male (CC0). `male-b.vrm`: VRoid Sakurada Fumiriya (CC0). Original embedded metadata is preserved.

## Authored in this project
Cottages, terrain, water, grass, procedural trees, bridges, pier, garden plots, creatures, hats, accessories, fabric patterns, UI icons and sounds are authored in code. Heartopia is a gameplay and mood reference only; no Heartopia assets, names or branding are used.
