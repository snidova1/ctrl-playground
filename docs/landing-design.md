# CTRL spatial index / launch direction

Concrete references inspected 2026-10-05 from threejs.org's current gallery: Bruno Simon (spatial navigation), Hervé Studio Badge Factory (tactile object interaction), David Greenheck Tidewater (responsive environmental surface). Technical reference: Three.js CSS3D periodic-table transformations. These are references, not copied assets or endorsement.

Design preflight: editorial asymmetry, Geist + IBM Plex Mono; a navigable field of actual world modules; GSAP object transitions and short typography reveals. The original CTRL brief takes precedence over a generic AIDA/features/pricing template. No testimonials, fake metrics, stock imagery, forced scroll pinning or scroll-jacking. H1 occupies the full width with two lines maximum. Three modules fill the scene; ordinary links duplicate every spatial action. Desktop pointer controls become touch selection on mobile. Reduced-motion mode stops ambient motion. Neutral ink/paper shell; individual worlds supply color.

The landing index exposes Commands, Work, Worlds, Archive, Machine and Account. Live status comes from API records. Demonstration worlds are explicitly identified. The launch state is read from server configuration and never inferred from possession of an Orbio API key.
