# CTRL visual system

CTRL is an institution with working rooms, not a marketing funnel. Paper, charcoal and vermilion connect navigation, the operator passport and permanent records. Worlds introduce independent material palettes.

## References selected with the user

The user requested existing projects featured on threejs.org, not isolated rendering examples. References are [Lusion](https://lusion.co/) for physical interaction, [Musée](https://musee.barvian.me/) for curated spatial exhibits, and [Igloo](https://www.igloo.inc/) for quiet environmental composition. Their assets, source code and identity are not copied.

The homepage is a selectable mechanical exhibit. Changing rooms changes its geometry; real public command and receipt counts inform its annotations. Dragging changes the viewing angle. The Command Arena gives supported missions more mass and pulls them inward, with collision separation. A parallel list provides keyboard access.

## Materials and rendering

Geist variable and IBM Plex Mono provide shared typography. No decorative model is downloaded on the home route. The atrium and arena use Three.js CSS3DRenderer, so spatial interaction also works without WebGL. The Dead Web uses React Three Fiber with a CSS3D archive fallback; Internet Weather uses layered Canvas contours; Agent Orbit uses R3F and a mobile SVG map. Each world is lazy loaded.

Mobile presents a composed exhibit and touch-friendly command index. Important world information remains available in DOM catalogues and inspectors. Reduced motion, visibility suspension, contrast and keyboard focus are part of the rendering contract. No scroll pinning, autoplay audio, fake testimonials or token yield claims are used.
